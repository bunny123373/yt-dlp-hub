Quick Reference

Ready-to-Use Commands

Best quality video
yt-dlp -f "bestvideo+bestaudio" --merge-output-format mp4 URL
Audio only MP3
yt-dlp -x --audio-format mp3 --audio-quality 0 URL
Playlist download
yt-dlp --yes-playlist -o "%(playlist)s/%(title)s.%(ext)s" URL
4K + subtitles
yt-dlp -f "bestvideo[height<=2160]+bestaudio" --embed-subs URL
With browser cookies
yt-dlp --cookies-from-browser chrome URL
Self-update
yt-dlp -U
